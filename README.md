# Shri Leela Charitra – Digital Granth

This repository contains a static reading library for the included Leela Charitra EPUB and glossary PDFs.

## Publish with GitHub Pages
1. Upload the contents of this project to the root of your GitHub repository (not the enclosing ZIP folder).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish, then open your Pages URL.

The homepage is `index.html`. It links to the EPUB reader, the existing literature section, both glossary PDFs, and the downloadable EPUB.

## Files
- `epub.html`: EPUB reader for `Amhi.epub`.
- `PURVARDH SHABDARTH.pdf`: Purvardh glossary.
- `UTTARARDH SHABDARTH.pdf`: Uttarardh glossary.
- `main/index.html`: existing literature collection.

Only publish materials you have permission to share publicly. This static site does not provide private document access or user authentication.
